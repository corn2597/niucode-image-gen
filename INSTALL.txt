NiuCodes Image Gen installation

Install from the current Gitee release with the repository bootstrap script.
The script asks for the API key without displaying it, verifies the release SHA-256,
installs into Codex, then writes config.json. It does not call the image API.

macOS:
  curl -fL https://gitee.com/niucodes/niucode-image-gen/raw/main/install-macos.command -o install-macos.command
  chmod +x install-macos.command && ./install-macos.command

Windows:
  Download https://gitee.com/niucodes/niucode-image-gen/raw/main/install-windows.cmd
  Double-click install-windows.cmd

No Node.js, Python, OpenAI SDK, or administrator permission is required.
Restart Codex Desktop after installation.
